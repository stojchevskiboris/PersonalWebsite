Alternativna Medicina E-Commerce

A full-stack web application built for alternative medicine content and product delivery, featuring a decoupled three-tier architecture.

Powered by a TypeScript & Express.js REST API with MongoDB/Mongoose on the backend, alongside separate Next.js 16 applications for both the admin management panel and public website.

Features: secure JWT and API-key authorization, TipTap rich-text blog management, automated file logging with Winston, product catalog management, and a responsive Radix/Tailwind UI.

Apartment Reservation Web App
